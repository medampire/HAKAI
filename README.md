# HAKAI

### Unlock More. Create More. Experience More.

**HAKAI** is a community-driven project dedicated to expanding the possibilities of Akai MPC standalone hardware.

From custom applications and plugins to system enhancements and additional functionality, HAKAI is all about pushing the boundaries of what your MPC can do.

**More freedom. More creativity. More possibilities.**

---

## About HAKAI

HAKAI aims to bring new capabilities to Akai MPC standalone devices by providing tools, enhancements and custom software developed for the MPC ecosystem.

Our mission is simple: give users more control over their hardware and encourage innovation within the MPC community.

This repository serves as the official distribution point for HAKAI releases.

## Supported Devices

HAKAI development covers various devices in the Akai MPC ecosystem, including:

- MPC X / MPC X SE
- MPC Live / Live II / Live III
- MPC One / One+ / One Gen2
- MPC XL
- MPC Key series
- Akai Force / Force II (both soon)

**Note:** Compatibility depends on the specific release. Not every feature or payload is available for every device.
